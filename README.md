## 🚀 How to Run & Preview the Website

### Option 1: Direct Browser Open (Zero Setup)
Simply open `index.html` in your web browser (Google Chrome, Safari, Microsoft Edge):
```bash
open /Users/samarpan/swastik/mr-wala-store/index.html
```

### Option 2: Run with Local HTTP Server
Using Python:
```bash
cd /Users/samarpan/swastik/mr-wala-store
python3 -m http.server 3000
```
Then visit **http://localhost:3000** in your browser.

Or using Node.js / npx:
```bash
npx serve /Users/samarpan/swastik/mr-wala-store -l 3000
```
